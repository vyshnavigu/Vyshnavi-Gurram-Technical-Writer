## Featured Project

### DocFlow AI: AI-Assisted Documentation Pipeline

[View the DocFlow AI repository](https://github.com/vyshnavigu/docflow-ai)

DocFlow AI is a personal project that explores how
technical documentation can be generated and maintained
using OpenAPI, Python, GitHub Actions, and an AI model.

The project demonstrates:

- Generating Markdown API documentation from OpenAPI.
- Identifying documentation changes through GitHub Actions.
- Preparing documentation drafts from Jira-style tickets.
- Reviewing AI-generated content against source documents.
- Detecting selected documentation quality issues.
- Testing quality checks with known failing and clean samples.
- Using pull requests and review checklists to manage changes.

The project also documents the problems encountered
during development and how they were investigated
and corrected.
